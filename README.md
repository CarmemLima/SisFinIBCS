# SisFinIBCS
Projeto SisFinIBCS - Sistema Financeiro Igreja Batista Centro Sul.

Aplicação web desenvolvida como projeto acadêmico, com o objetivo de aplicar, de forma prática, conhecimentos adquiridos ao longo da graduação no desenvolvimento de uma solução voltada a uma necessidade real da comunidade local.

O projeto foi criado em linguagem Java com POO, com banco de dados MySQL.

A aplicação está hospedada na plataforma Render. Por ser opensource é uma das plataformas que hospeda projetos server-side (back-end). Não foi possível hospedar no Vercel ou Netfily, pois estas hospedam apenas aplicações client-side (voltadas ao front-end, com interface HTML e CSS).

O banco de dados foi construído no MySQL e hospedado no Aiven, que é uma plataforma em nuvem, opensource, que permite hospedar e gerenciar o banco de dados de forma segura e flexível.

Com tempo de inatividade essas plataformas de hospedagem ficam offline, sendo necessário ativá-las novamente, no dashboard de cada uma delas, para que a página abra no navegador publicamente.
